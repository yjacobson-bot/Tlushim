# תלושים — ניהול ת"ת

אפליקציה לניהול מכירת תלושים בישיבה / ת"ת.

## הורדת APK

1. לחץ על **Actions** בגיטהאב
2. לחץ על ה-run האחרון של "Build Android APK"
3. גלול למטה ל-**Artifacts** → הורד `tlushim-debug-apk`
4. חלץ את הקובץ ופתח את `app-debug.apk` בטלפון

> ⚠️ בטלפון: הגדרות → אפליקציות → התקן מקורות לא ידועים → אפשר

## פיצ'רים

- ניהול חנויות ומוצרים/תלושים
- רישום רכישות בחורים עם חישוב אוטומטי
- מעקב חובות פתוחים
- היסטוריית העברות תשלום לחנויות
- עובד **100% ללא אינטרנט**
- שומר נתונים מקומית בטלפון
